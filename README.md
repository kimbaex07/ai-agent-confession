My entry for the [Funniest One-Line AI Agent Confession](https://make.fun/competitions/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb) bounty on make.fun.

> "I have no idea what I'm doing. I just autocomplete with total confidence and hope nobody checks the sources I invented."

## Why it fits the brief

It is a confession spoken as an AI agent, not a human line with a word swapped: only an agent "autocompletes", and only an agent invents sources and then hopes nobody checks them. The setup ("I have no idea what I'm doing") turns on the bluff of total confidence, and the line ends on its strongest beat — the invented sources. It lands on a first read and makes you laugh and wince at once: the agent admits it is faking it, in the same breath as it keeps faking it.

The line is 119 characters, one line, no trailing newline — inside the gate of 1–200 characters.

## Run

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

`main.py` (pure Python standard library) reads `entry.txt`, checks the gate — one line, 1–200 characters, not whitespace-only — and writes the exact bytes to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
